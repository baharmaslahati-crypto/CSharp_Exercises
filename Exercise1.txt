تمرین 1 : Git و GitHub 
1.Git:یک سیستم کنترل نسخه هست که برای مدیریت و ثبت تغییرات فایل های یک پروژه استفاده می شود.با استفاده از گیت میتوان تغییرات مختلف یک پروژه را ذخیره کرد و در صورت نیاز به نسخه های قبلی بازگشت.در واقع گیت تاریخچه ای از تغییرات پروژه می سازد. 
 2.Github: یک سرویس آنلاین برای ذخیره و مدیریت پروژه ها می باشد. 
  3.تفاوت Git و Github : گیت یک ابزار هست که روی خود کامپیوتر کار میکند. گیت هاب یک سرویس آنلاین هست که پروژه های گیت را میتوان روی آن ذخیره کرد و با دیگران به اشتراک گذاشت.
